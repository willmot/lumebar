## LumeBar 1.0.0-beta4

Beta 4 refreshes the menu and Settings and makes the selected Lume service responsible for listing, starting, and stopping VMs. VMs with the same name in different storage locations are handled separately.

- Start headless with or without Lume VNC, or start with a display.
- Choose a Screen Sharing source per VM. The inline preview takes a read-only snapshot and waits for a visible frame during boot.
- Save a guest login in Keychain to preview its own Screen Sharing service. Enter the login again if you used a build that saved it by VM name alone.

### Compatibility

- Apple silicon and macOS 26 or later
- Lume 0.6.0 or later for starts without Lume VNC
- Bundle version `1.0.0`, build `104`

See the [README](../README.md) for service setup and Screen Sharing configuration.
